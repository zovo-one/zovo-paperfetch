I write the code.
I keep it working.

I build Zovo on my own. There’s more to a useful extension than its first release: browser updates, bug fixes, testing, and security maintenance all take time.

Membership helps cover that work. It gives me more room to improve the tools you use and to keep building with public code and privacy in mind.

If you’ve found value here, I’d appreciate your support.
